# 1.0 Introduction
---
 Model은 Input space에서 Output space로 향하는 **Mapping**이다. 우리의 관측(target) $y$는 현실에 존재하는 미지의 완벽한 규칙 $f$와 관측 단계에서의 오차 $\epsilon$에 대해 $y=f(x)+\epsilon$라고 할 수 있다. [[0. Introduction and Motivation|ML.0]]에서 보았듯이, 우리는 $y$를 완벽하게 예측할 수 없기때문에, 입력(input) $x$를 받아 $y$를 예측하는 근사 함수(hypothesis)를 설계하고 이를 model이라고 부른다. 이때, model의 함숫값, 즉 **예측값**(prediction)을 $\hat{y}$로 표기한다.
 
 Regression은 **continuous** 한 예측을 수행하는 것을 말한다. 가령 부모의 키를 입력받아 자식의 키를 예측하는 과제는 regression이라 부를 수 있다. Linear regression은 입력과 출력 간의 관계가 **선형**이라는 가정하에, $f(x;w,b)=\sum_i{w_ix_i}+b$꼴로 예측하는 것이다. 이때, $x_i$는 우리가 가지고 있는 데이터의 **특징**(feature)이고 위 예시에서는 `father_height`, `mother_height`등이 있을 수 있다. $w_i$와 $b$는 linear combination의 계수 정도로 이해하고 넘어가고 유래에 대해서는 [[1. Artificial Neural Network(ANN)|DL.1]]에서 자세히 다루겠다.

 가장 중요한 것은, linear regression model은 훈련중엔 보지 못한(unseen) sample들의 target value와 prediction의 오차(error)를 최소화하는 것이다. 이를 위해 훈련 과정에서는 $w_i$, $b$가 훈련 샘플(training data)에서의 error를 줄이는 방향으로 이리 저리 움직여가며 적절한 값을 찾아내는 과정이라고 볼 수 있다. 자연스레, training sample의 target value가 필수적이게 되는데 이를 **지도학습**(supervised learning)이라고 부른다.

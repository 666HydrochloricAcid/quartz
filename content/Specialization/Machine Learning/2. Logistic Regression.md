# 2.0 Introduction
---
Classification은 regression과 반대로, **discrete**, **categorical**한 예측(Class, Category, Label)을 수행하는 것을 말한다. 예측하려는 target의 형태에 따라 크게 세 가지로 나뉘는데 다음과 같다.

- Binary Classification : Label의 종류가 2개인 경우 (True / False, 개 / 고양이, 성공 / 실패, 등)
- Multi-Class Classification : Label의 종류가 3개 이상이며, 그중 1개로 예측하는 경우 (개 / 고양이 / 새, handwritting letter를 구별하는 경우, 등)
- Multi-Label Classfication : Target이 여러 개의 Label을 동시에 가질 수 있는 경우 (한 영화에 'SF', 'Comedy', 등 여러 장르를 부여할 수 있는 경우, 등)

 가령, 이미지를 입력받으면 그것이 개(0)인지, 고양이(1)인지 예측하는 문제는 binary classification에 해당하며, Logistic Regression Model은 이러한 binary classification을 수행하는 모델이다. 그것이 이름과는 다르게 binary classification에 사용되는 이유는, 그것이 예측을 산출하는 방식에 있다. Model은 입력받은 image가 고양이인 확률 $0<P(x=1)<1$, 즉, 출력이 continuous하기 때문이다.

 결정적으로 분류를 하기위해서는 **threshold**가 필요하고 이는 #hyperparameter 이다. 즉, $P(x=1)$가 0.5보다 크면 1로 분류하라는 식으로 명령하여, 실제로 분류 작업을 수행하게 되는데, 0.5를 택하는 것은 결국 인간의 결정인것이다. ~~Precision and Recall 백링크~~

# 2.1 Sigmoid
---
 또한, Logistic Regression은 Logit(Log-Odds)에 대한 Linear Regression으로 볼 수 있다. $p$를 이미지 $x$가 고양이일 확률 $P(x=1)$라 한다면, odds는 사건이 일어나지 않을 확률대비 일어날 확률의 비율이고, logit은 이에 로그를 취한 형태이다 :

$$
\text{Odds}:=\cfrac{p}{1-p},\qquad 0<\text{Odds}<\infty
$$
$$
\text{Logit}:=\ln{\cfrac{p}{1-p}}=\mathbf{Wx}+b=z,\qquad 0<\text{Logit}<1\tag{1}
$$

이때, 단순히 확률 $p$에 linear regression을 하지 않는 이유는, 확률공간의 정의에 따라, $\mathbf{Wx}+b$는 0과 1사이의 값만 가져야하는데, $(-\infty, \infty)$의 값을 갖기 때문에, 위의 수식을 통해 치역을 일치시킬 수 있다. 이때, 식 $(1)$을 $p$에 대해 정리하면 다음과 같다 :

$$
p=\cfrac{1}{1+e^{-\mathbf{Wx}+b}}=:\text{sigmoid}\left(\mathbf{Wx}+b\right)
$$
 이때, 함수 $\text{sigmoid}:\mathbb{R}^n\rightarrow(0,1)$ 를 sigmoid 함수라 하고, linear regression의 output인 logit을 입력받으면, $p$를 출력한다. 즉, linear regression model의 출력부에 sigmoid 함수만 추가된 것이 logistic regression인 것이다.

# 0.2 Sigma algebras and Borel sets
---
<div class="def">

**Definition 0.1 [$\sigma$-algebra]** Given a set $X$, a collection $\mathcal{A} \subseteq \mathcal{P}(X)$ is called a $\sigma$-algebra of subsets of $X$ if $\mathcal{A}$ satisfies the following properties :^def-0-1

1. $\emptyset \in \mathcal{A}$
2. $A \in \mathcal{A} \implies A^c \in \mathcal{A}$
3. $\left\{A_i\right\}_{i=1}^{\infty}\subseteq\mathcal{A} \implies\bigcup_{i=1}^{\infty} A_i \in \mathcal{A}$

</div>

 Given a set $X$, one can easily prove that each collection $\set{\emptyset,\ X}$, and $\mathcal{P}(X)$ is clearly a $\sigma$-algebra.

**Remark 0.2** If $\mathcal{A}$ is $\sigma$-algebra of subsets of $X$, then
1. $X \in \mathcal{A}$
2. $\set{A_i}_{i=1}^{\infty}\subseteq\mathcal{A} \implies\bigcap_{i=1}^{\infty} A_i \in \mathcal{A}$

 One can easily show the above propositions by using [[0. Introduction and Preliminaries#^def-0-1-mt|Def 0.1]] and the [[0. Introduction to Set Theory|De Morgan's Law]].

**Theorem 0.3** Let $\mathcal{F}$ be a collection of subsets of a given set $X$. Then, the intersection of all $\sigma$-algebras that contain $\mathcal{F}$ is a $\sigma$-algebra. Moreover, it is the smallest $\sigma$-algebra that contains $\mathcal{F}$.

<details class="proof">
<summary>Proof.</summary>

Define $\Sigma$, and $\mathcal{A}$ as follows :

$$
\Sigma=\left\{ \mathcal{M} \subseteq \mathcal{P}(X) : \mathcal{M} \text{ is a } \sigma\text{-algebra and } \mathcal{F} \subseteq \mathcal{M} \right\},\qquad\mathcal{A} = \bigcap_{\mathcal{M} \in \Sigma} \mathcal{M}.
$$

 Since $\mathcal{P}(X)$ is a $\sigma$-algebra containing $\mathcal{F}$, we have $\mathcal{P}(X) \in \Sigma$, so $\Sigma \neq \emptyset$ and $\mathcal{A}$ is well-defined.

 Now, we show that $\mathcal{A}$ is a $\sigma$-algebra.

(i) Since $\emptyset \in \mathcal{M}$ for every $\mathcal{M} \in \Sigma$, we have $\emptyset \in \mathcal{A}$.

(ii) Let $E \in \mathcal{A}$. For each $\mathcal{M} \in \Sigma$, $E \in \mathcal{M}$, and hence $E^c \in \mathcal{M}$ since $\mathcal{M}$ is a $\sigma$-algebra. Thus $E^c \in \mathcal{A}$.

(iii) Let $\{E_i\}_{i=1}^{\infty} \subseteq \mathcal{A}$. For each $\mathcal{M} \in \Sigma$, $\{E_i\}_{i=1}^{\infty} \subseteq \mathcal{M}$, and hence $\bigcup_{i=1}^{\infty} E_i \in \mathcal{M}$. Thus $\bigcup_{i=1}^{\infty} E_i \in \mathcal{A}$.

 Next, if $E \in \mathcal{F}$, then $E \in \mathcal{M}$ for every $\mathcal{M} \in \Sigma$ by the definition of $\Sigma$, so $E \in \mathcal{B}$. Hence $\mathcal{F} \subseteq \mathcal{A}$.
 
 Moreover, let $\mathcal{B}$ be any $\sigma$-algebra of subsets of $X$ containing $\mathcal{F}$. Then $\mathcal{B} \in \Sigma$ by the definition of $\Sigma$, and therefore
 
$$
\mathcal{A} = \bigcap_{\mathcal{M} \in \Sigma} \mathcal{M} \subseteq \mathcal{B}.
$$

 Consequently, $\mathcal{A}$ is the smallest $\sigma$-algebra that contains $\mathcal{F}$.
 </details>
 
<div class="def">

**Definition 0.4 [Borel Sets]** Given a topological space $X$, the smallest $\sigma$-algebra that contains every open set in $X$ is called the **Borel $\sigma$-algebra**, denoted by $\mathcal{B}(X)$ and each member of $\mathcal{B}(X)$ is called a **Borel set**.^def-0-4

</div>

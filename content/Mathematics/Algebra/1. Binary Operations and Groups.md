# 1. 1 Binary Operations
---
Abstract algebra is primarily concerned with the study of operations analogous to the addition and multiplication of numbers. We first define such operations in this section and examine some of their general properties. The addition process for numbers assigns to any ordered pair $(a,b)$ of numbers a new number, their sum, denoted $a+b$. Similarly, multiplication assigns the product $ab$ to the pair $(a,b)$.

In general, we define such operations as follow.

<div class='def'>

**Definition 1.1.1 \[Binary Operations\]** Let $M$ be a set. A **binary operation**  $*$ on a set $M$ is a mapping that assigns to each ordered pair $(a,b)$ of elements of $M$ an element $a*b$ of $M$.

In this case, $M$ is said to be **closed** under the binary operation

</div>

We will give a name for each property of binary operations.

<div class='def'>

**Definition 1.1.2 \[Basic Properties for binary operations\]** Let $M$ be a set, and $*$ be a binary operation on M. Then,

1. $*$ is called **commutative** if $a*b=b*a$ for all $a$, $b$ in $M$.
2. $*$ is called **associative** if $a*(b*c)=(a*b)*c$ for all $a$, $b$, $c$ in $M$.
3. An element $e$ in $M$ is called an **identity** (or a **unity**) for $*$ if $a*e=e*a=a$ for all $a$ in $M$.

</div>

Some authors call $e$ the **unity** of $M$; in this series, we shall call it the **identity** of $M$.

<div class='thm'>

**Theorem 1.1.3** If a binary operation has an identity element, that identity is unique.

</div>

<details class="proof">
<summary>Proof.</summary>

If  $e$ and $f$ are both identities, then $f=e*f=e$. So $e=f$

</details>

def<>

**Definition 1.1.4 \[Monoid\]** A set $M$ is called a **monoid** if a binary operation is defined on $M$ that is associative and has an identity. We say that $(M,*)$ is a monoid if the operation $*$ must be emphasized. If the operation is commutative, we say that $M$ is a **commutative monoid**.

# 9.1 Rings
---
From now on, we are going to think about some structures equipped with **two** binary operations.

<div class='def'>

**Definition 9.1.1 \[Rings\]** A set $R$ is called a **ring** if it has two binary operations, written as addition and multiplication, satisfying for all $a$, $b$, and $c$ in $R$ :

&emsp;$(\text{R}1)$&emsp;$a+b=b+a$,

&emsp;$(\text{R}2)$&emsp;$a+(b+c)=(a+b)+c$,

&emsp;$(\text{R}3)$&emsp;There exists $0\in R$ such that $0+a=a$ for all $a\in R$,

&emsp;$(\text{R}4)$&emsp;For each $a\in R$, there exists $-a\in R$ such that $a+(-a)=0$,

&emsp;$(\text{R}5)$&emsp;$a(bc)=(ab)c$,

&emsp;$(\text{R}6)$&emsp;There exists $1\in R$ such that $1a=a1=a$ for all $a\in R$,

&emsp;$(\text{R}7)$&emsp;$a(b+c)=ab+ac$ and $(b+c)a=ba+ca$.

And $R$ is called a **commutative ring** if, in addition,

&emsp;$(\text{R}8)$&emsp;$ab=ba$.

</div>

The first four axioms gives that a ring $R$ is an additive abelian group. The additive unity 0 in $(\text{R}3)$ is called the **zero** of $R$, and the additive inverse $-a$ of $a$ in $(\text{R}4)$ is called the **negative** of the element $a$. $(\text{R}5)$ and $(\text{R}6)$ gives that $R$ is a multiplicative monoid, so the element 1, called the **unity** of $R$, is unique. If the ring must be emphasized, we write the zero and unity as $0_R$ and $1_R$. Each identity in $(\text{R}7)$ is called the the **(left and right) distributive law**, and this connects addition and multiplication.

Some authors call any structure satisfying all of the axioms except possibly $(\text{R}6)$ a ring, but we shall instead call such a structure a **general ring**.

In addition, when the operations, zero, or unity of a ring $R$ are not the usual ones, or when we want to emphasize them, we explicitly write that $(R,+_R,\cdot_R,0_R,1_R)$ is a ring. Otherwise, we simply say that $R$ is a ring and write $+$, $\cdot$, $0$, and $1$ without subscripts.

<div class='ex'>

**Example 9.1.2** The following is rings :
1. The set $R=\set{0}$ is a ring where $0+0=0$ and $0\cdot0=0$. It is called the **zero  ring** and denoted $R=0$.
2. Each of $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, and $\mathbb{C}$ is a commutative ring.
3. $\mathbb{Z}_n$ is a commutative ring for each $n\ge2$.
4. $M_n(\mathbb{R})$ equipped with matrix addition and multiplication is a ring, where $0_{M_n(\mathbb{R})}=0_n$ and $1_{M_n(\mathbb{R})}=I_n$. It is not commutative if $n\ge2$.
5. $\mathbb{R}[x]$ equipped with usual addition and multiplication is a commutative ring.
6. If $X$ is a nonempty set, then the set $F(X,\mathbb{R})$ of all functions $X\to\mathbb{R}$, equipped with pointwise addition and multiplication is a commutative ring, where $0_{F(X,\mathbb{R})}$ is the zero function and $1_{F(X,\mathbb{R})}$ is the constant function 1.
7. If $R_1$, $R_2$, $\cdots$, $R_n$ be rings, then the Cartesian product $R=R_1\times R_2\times\cdots\times R_n$ equipped with componentwise addition and multiplication is a ring, where $0_R=(0_{R_1},0_{R_2},\cdots,0_{R_n})$ and $1_R=(1_{R_1},1_{R_2},\cdots,1_{R_n})$. Moreover, it is commutative if and only if each $R_i$ is commutative.

Since a ring $R$ is an additive abelian group, the laws of exponents take on a different form : For $n\in\mathbb{Z}$ and $a\in R$, we write the $n^{\text{th}}$ power $a^n$ of a as the $n^{\text{th}}$ multiple $na$ of $a$ in an additive group.

<div class='thm'>

**Theorem 9.1.3** For all $r\in R$, $0\cdot r=r\cdot0=0$.

</div>

<details class="proof">
<summary>Proof.</summary>

$$
\begin{align*}
0\cdot r+0\cdot r&=(0+0)\cdot r \tag{\text{R}7}\\
&=0\cdot r\tag{\text{R}3}\\
&=0\cdot r+0\tag{\text{R}3}\\
\end{align*}
$$
This gives that

$$
\begin{align*}
&(-0\cdot r)+0\cdot r+0\cdot r=(-0\cdot r)+0\cdot r+0\tag{\text{R}4}\\
\implies&(-0\cdot r+0\cdot r)+0\cdot r= (-0\cdot r+0\cdot r)+0\tag{\text{R}2}\\
\implies&0+0\cdot r=0+0\tag{\text{R}4}\\
\implies&0\cdot r=0\tag{\text{R}3}\\
\end{align*}
$$

Similarly, we can obtain that $r\cdot0=0$.

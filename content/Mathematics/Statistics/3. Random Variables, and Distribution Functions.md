# 3.1 Random Variables
---
In many experiments, it is easier to deal with a summary variable than with the original probability structure. For example, in an opinion poll, we might decide to ask 50 people whether they agree or disagree with a certain issue. If we record a "$1$" for agree and "$0$" for disagree, the sample space for this experiment has $2^{50}$ elements, each an ordered string of $1$s and $0$s of length $50$. We should be able to reduce this to a reasonable size. It may be that the only quantity of interest is the number of people who agree (equivalently, disagree) out of $50$ and, if we define a variable $X =$ number of ls recorded out of $50$, we have captured the essence of the problem. Note that the sample space for $X$ is the set of integers $\set{0, 1, 2,\cdots, 50}$ and is much easier to deal
with than the original sample space.

<div class='def'>

**Definition 3.1.1 \[Random Variables\]** A **random variable** is a function from a sample space $S$ into $\mathbb{R}$.

</div>

<div class='ex'>

**Example 3.1.2** Toss a fair coin $n$ times, so that $S=\set{\text{H},\text{T}}^n$ has $2^n$ elements. Writing $\omega=(\omega_1,\cdots,\omega_n)$ with $\omega_i\in\set{0,1}$, define

$$
X(\omega)=\sum^{n}_{i=1}\omega_i,
$$

the number of heads. Then $X$ is a random variable taking values in $\set{0,1,\cdots,n}$, and it replaces a sample space of size $2^n$ by one of size $n+1$.

If instead the coin is tossed forever, so that $S=\set{\text{H},\text{T}}^{\mathbb{N}}$, the function

$$
U(\omega)=\sum^{\infty}_{i=1}\frac{\omega_i}{2^i}
$$

is a random variable taking values in $[0,1]$: the series converges for every $\omega$, being dominated by $\sum_i2^{-i}=1$.

</div>

# 3.2 Distribution Functions
---
With every random variable $X$, we associate a function called the cumulative distribution function of $X$.

<div class='def'>

**Definition 3.2.1 \[Cumulative Distribution Functions\]** The **cumulative distribution function** ,**cdf** for short, of a random variable $X$, denoted by $F_X(x)$, is defined by

$$
F_X(x)=P_X(X\le x),\quad\text{for all }x.
$$

</div>

<div class='thm'>

Theorem 3.2.2 The function $F(x)$ is a cdf if and only if the following three conditions hold :

1. $\lim_{x\rightarrow-\infty}F(x)=0$ and $\lim_{x\rightarrow\infty}F(x)=0$,
2. $F(x)$ is a nondecreasing function of $x$,
3. $F(x)$ is right-continuous; that is, $\lim_{x\rightarrow x_0-}F(x)=F(x_0)$ for all $x_0$.

</div>

<details class="proof"> 
<summary>Proof.</summary>

$(\implies)$ Suppose $F=F_X$ for some random variable $X$ on a probability space $(S,\mathcal{B},P)$. Since $F$ is monotone by (ii), which we prove first, every limit below may be computed along an arbitrary monotone sequence.

(ii) Let $x\lt y$. Since $X(\omega)\le x$ implies $X(\omega)\le y$, we have $\set{X\le x}\subset\set{X\le y}$, and Theorem 1.2.5 (iii) gives $F(x)\le F(y)$.

(i) Let $x_n\downarrow-\infty$ and put $A_n=\set{X\le x_n}$. These sets decrease, and

$$
\bigcap^{\infty}_{n=1}A_n=\set{\omega: X(\omega)\le x_n\text{ for every }n}=\emptyset,
$$

since $X(\omega)$ is a real number and therefore exceeds $x_n$ for $n$ large. By Theorem 1.2.8 (ii) and Theorem 1.2.4 (i),

$$
\lim_{n\to\infty}F(x_n)=P\left(\bigcap^{\infty}_{n=1}A_n\right)=P(\emptyset)=0.
$$

Similarly, if $x_n\uparrow\infty$ and $A_n=\set{X\le x_n}$, these sets increase and $\bigcup_n A_n=S$, because every real number $X(\omega)$ is eventually dominated by $x_n$. Theorem 1.2.8 (i) gives $\lim_n F(x_n)=P(S)=1$.

(iii) Let $x_n\downarrow x_0$ and $A_n=\set{X\le x_n}$. These sets decrease, and

$$
\bigcap^{\infty}_{n=1}A_n=\set{\omega:X(\omega)\le x_n\text{ for every }n}=\set{\omega:X(\omega)\le\inf_n x_n}=\set{X\le x_0}.
$$

By Theorem 1.2.8 (ii), $\lim_n F(x_n)=P(X\le x_0)=F(x_0)$.

$(\Longleftarrow)$ Conversely, suppose $F$ satisfies (i)–(iii). We must exhibit a probability space and a random variable on it whose cdf is $F$. Take

$$
S=(0,1),\qquad \mathcal{B}=\text{the Borel subsets of }(0,1),\qquad P=\text{Lebesgue measure},
$$

and define

$$
X(u)=\inf\set{x\in\mathbb{R}: F(x)\ge u},\qquad u\in(0,1).
$$

The infimum is taken over a nonempty set bounded below. Fix $u\in(0,1)$ and write $A_u=\set{x:F(x)\ge u}$. Since $F(x)\to1$ as $x\to\infty$ and $u\lt1$, there is some $x$ with $F(x)\ge u$, so $A_u\neq\emptyset$. Since $F(x)\to0$ as $x\to-\infty$ and $u>0$, there is some $x_0$ with $F(x_0)\lt u$; by (ii) every $x\in A_u$ satisfies $x>x_0$. Hence $X(u)\in\mathbb{R}$.

We claim that for every $u\in(0,1)$ and every $x\in\mathbb{R}$,

$$
X(u)\le x\iff u\le F(x).\tag{$\ast$}
$$

($\Leftarrow$) If $u\le F(x)$ then $x\in A_u$, so $X(u)=\inf A_u\le x$.

($\Rightarrow$) We first show that the infimum is attained, that is, $F(X(u))\ge u$. Choose $t_n\in A_u$ with $t_n\downarrow X(u)$; such $t_n$ exist by the definition of the infimum. Then $F(t_n)\ge u$ for every $n$, and right-continuity (iii) gives

$$
F(X(u))=\lim_{n\to\infty}F(t_n)\ge u,
$$

so $X(u)\in A_u$. Now if $X(u)\le x$, monotonicity (ii) yields $F(x)\ge F(X(u))\ge u$.

Consequently, by (i) and (ii), $0\le F(x)\le1$ for every $x$. Using $(\ast)$,

$$
\set{u\in(0,1):X(u)\le x}=\set{u\in(0,1):u\le F(x)}=(0,F(x)]\cap(0,1),
$$

which is a Borel set; as these sets generate $\mathcal{B}$, the function $X$ is a random variable. Its Lebesgue measure is $F(x)$, and therefore

$$
F_X(x)=P(X\le x)=F(x)\qquad\text{for every }x,
$$

as required.

</details>

<div class='ex'>

**Example 3.2.3** Let $X$ be the number of heads in three tosses of a fair coin, as in Example 3.1.2 with $n=3$. Each of the eight sequences has probability $\tfrac18$, so

$$
P(X=0)=\tfrac18,\quad P(X=1)=\tfrac38,\quad P(X=2)=\tfrac38,\quad P(X=3)=\tfrac18,
$$

and the cumulative distribution function is

$$  
F_X(x)=\begin{cases}  
0, & x\lt0,\\[2pt]  
\tfrac18, & 0\le x\lt1,\\[2pt]  
\tfrac12, & 1\le x\lt2,\\[2pt]  
\tfrac78, & 2\le x\lt3,\\[2pt]  
1, & x\ge3.  
\end{cases}  
$$

$F_X$ is constant except at $0,1,2,3$, where it jumps by $P(X=x)$, and it is right‑continuous at each of these points, as Theorem 3.2.3 requires. Note that $F_X(1)=\tfrac12$ and not $\tfrac18$: the value at a jump is the larger of the two.

</div>

<div class='ex'>

**Example 3.2.4** Let $U$ be as in Example 3.1.2, the coin tossed infinitely often and read as a binary expansion. Fix $k$ and a finite string $(a_1,\cdots,a_k)\in\set{0,1}^k$. The outcomes whose first $k$ tosses agree with this string are exactly those for which

$$
U(\omega)\in\left[\,b,\ b+2^{-k}\,\right),\qquad b=\sum^{k}_{i=1}\frac{a_i}{2^i},
$$

and this event has probability $2^{-k}$ by the mutual independence of the tosses. The $2^k$ intervals so obtained partition $[0,1)$ into pieces of equal length, each receiving equal probability, and letting $k\to\infty$ gives

$$
F_U(u)=P(U\le u)=u,\qquad 0\le u\le1,
$$

with $F_U(u)=0$ for $u\lt0$ and $F_U(u)=1$ for $u>1$. This function is continuous, so by Definition 3.2.6 the random variable $U$ is continuous, and in particular $P(U=u)=0$ for every $u$.

</div>

<div class='def'>

**Definition 3.2.5** A random variable $X$ is called to be **discrete** if there exists a countable set $S$ with $P(X\in S)=1$. On the other hand, $X$ is called to be **continuous** if $F_X(x)$ is a continuous function of $x$, equivalently P(X = x) = 0 for all x.

</div>

<div class='def'>

**Definition 3.2.6** The random variables $X$ and $Y$ are identically distributed if for every set $A\in\mathcal{B}$, $P(X\in A)=P(Y\in A)$.

</div>

<div class='ex'>

**Example 3.2.7** Toss a fair coin $n$ times and let $X$ be the number of heads and $Y$ the number of tails. These are different functions on $S$; indeed $X+Y=n$, so $X(\omega)=Y(\omega)$ for no $\omega$ at all when $n$ is odd. Nevertheless, for each $k$ the sequences with $k$ heads are in bijection with those with $k$ tails under the exchange of the two symbols, so

$$
P(X=k)=\binom{n}{k}\frac{1}{2^n}=P(Y=k),\qquad k=0,1,\cdots,n,
$$

and $X$ and $Y$ are identically distributed. Equality in distribution is therefore much weaker than equality of random variables.

</div>

<div class='thm'>

**Theorem 3.2.8** The followings are equivalent :

1. The random variables $X$ and $Y$ are identically distributed.
2. $F_X(x)=F_Y(x)$ for all $x$.

</div>

<details class="proof">
<summary>Proof.</summary>

Throughout, write $P_X(A)=P(\set{\omega\in S:X(\omega)\in A})$ for $A\in\mathcal{B}(\mathbb{R})$. This is a probability function on $\mathcal{B}(\mathbb{R})$ : it is nonnegative, $P_X(\mathbb{R})=P(S)=1$, and if $A_1,A_2,\cdots$ are pairwise disjoint then so are the sets $\set{X\in A_i}$, whence countable additivity follows from $(\text{P}3)$ applied in $S$. With this notation, Definition 3.2.7 reads $P_X=P_Y$ on $\mathcal{B}(\mathbb{R})$, and $F_X(x)=P_X((-\infty,x])$.

(i) $\Rightarrow$ (ii). Each half-line $(-\infty,x]$ is a Borel set, so taking $A=(-\infty,x]$ in Definition 3.2.6 gives

$$
F_X(x)=P_X\big((-\infty,x]\big)=P_Y\big((-\infty,x]\big)=F_Y(x)
$$

for every $x$.

(ii) $\Rightarrow$ (i). Suppose $F_X=F_Y$ and set

$$
\mathcal{D}=\set{A\in\mathcal{B}(\mathbb{R}):P_X(A)=P_Y(A)},
$$

the collection of Borel sets on which the two agree. We show that $\mathcal{D}$ is a $\lambda$-system.

- $\mathbb{R}\in\mathcal{D}$, since $P_X(\mathbb{R})=1=P_Y(\mathbb{R})$.
- If $A\in\mathcal{D}$, then by Theorem 1.2.4 (iii),  

$$
P_X(A^c)=1-P_X(A)=1-P_Y(A)=P_Y(A^c),
$$

so $A^c\in\mathcal{D}$.
- If $A_1,A_2,\cdots\in\mathcal{D}$ are pairwise disjoint, then by $(\text{P}3)$,  

$$
P_X\left(\bigcup^{\infty}_{i=1}A_i\right)=\sum^{\infty}_{i=1}P_X(A_i)=\sum^{\infty}_{i=1}P_Y(A_i)=P_Y\left(\bigcup^{\infty}_{i=1}A_i\right),
$$

so $\bigcup_i A_i\in\mathcal{D}$.

Next, let

$$
\mathcal{C}=\set{(-\infty,x]:x\in\mathbb{R}}.
$$

This is a $\pi$-system, since $(-\infty,x]\cap(-\infty,y]=(-\infty,\min(x,y)]\in\mathcal{C}$, and it generates the Borel $\sigma$-algebra, $\sigma(\mathcal{C})=\mathcal{B}(\mathbb{R})$. The hypothesis $F_X=F_Y$ says precisely that $\mathcal{C}\subset\mathcal{D}$.

By Dynkin’s $\pi$–$\lambda$ theorem, a $\lambda$-system containing a $\pi$-system contains the $\sigma$-algebra generated by it, so

$$
\mathcal{B}(\mathbb{R})=\sigma(\mathcal{C})\subset\mathcal{D},
$$

that is, $P_X(A)=P_Y(A)$ for every Borel set $A$. Hence $X$ and $Y$ are identically distributed.

</details>
